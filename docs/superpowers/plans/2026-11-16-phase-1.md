# Phase 1 — kế hoạch triển khai

**Goal:** Từ trình duyệt tiếng Việt, đăng ký/đăng nhập, lưu hồ sơ, xem chỉ số, đổi mật khẩu và đăng xuất; dữ liệu giữ trong PostgreSQL.

**Spec:** `docs/AGENTS.md`, `docs/PLAN (1).md`, `docs/Danh_sach_30_bang_CSDL.md`, lịch Phase 1 trong DOCX.

**Đã chốt trong phiên:** Maven + Flyway, users ACTIVE/LOCKED; người dùng yêu cầu thêm đăng ký và đổi mật khẩu ngay Phase 1.

**Architecture:** Next.js/TypeScript/Tailwind gọi `/api/v1` cùng origin qua proxy; một Spring Boot Java 21 chia module auth/profile/calculation; PostgreSQL + pgvector. Spring Security xác thực bằng phiên server, CSRF và cookie HttpOnly. Flyway quản lý schema. Không cần AI để hoàn thành luồng hồ sơ/chỉ số.

**Lựa chọn:** Maven Wrapper và Flyway SQL phù hợp repo mới và DDL PostgreSQL; Gradle/Liquibase không đem thêm giá trị cho phạm vi này. Triển khai ngay trong checkout người dùng đã cung cấp, giữ các tài liệu chưa được git theo dõi.
